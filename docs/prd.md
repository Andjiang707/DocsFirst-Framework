# 📝 Product Requirements Document (PRD): FocusFlow 番茄鐘

## 1. 產品概述
**FocusFlow** 是一個極簡主義的網頁版番茄鐘計時器，旨在幫助開發者和創作者進入「心流」狀態。它屏除所有不必要的干擾，僅提供核心計時與統計功能。

## 2. 核心功能 (Core Features)

### 2.1 計時器控制
- **預設時間**：25 分鐘（專注）/ 5 分鐘（休息）。
- **操作行為**：
  - `Start`：開始倒數。
  - `Pause`：暫停倒數（時間停止）。
  - `Reset`：重置回目前的預設時間。
- **視覺回饋**：
  - 倒數時，網頁 Title 需同步顯示剩餘時間 (e.g., "24:59 - FocusFlow")。
  - 時間結束時，顯示瀏覽器通知 (Notification API)。

### 2.2 任務統計
- 簡單計數器，顯示今日已完成的番茄鐘數量。
- 儲存於 LocalStorage，隔日自動重置（或手動清除）。

### 2.3 音效提示
- 結束時播放簡短、不刺耳的提示音。
- 提供靜音按鈕。

## 3. 使用者介面 (UI/UX)
- **風格**：Neo-Brutalism (新野獸派) 或 極簡黑白風格。
- **主畫面**：
  - 中央超大字體顯示時間 (e.g., `25:00`)。
  - 下方三個按鈕：Start, Pause, Reset。
  - 右上角：靜音切換。
  - 左下角：今日完成數。

## 4. 限制與邊界條件
- 不需後端，純前端運作。
- 必須支援手機瀏覽器 RWD。
